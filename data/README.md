# Data Directory

After downloading and extracting the NEMSIS Cardiac Arrest dataset, place the extracted `CardiacArrestPUD2023` directory inside the local `data/` folder before running the notebooks.

Dataset source:
https://nemsis.org/datasets/

Raw datasets are not included in this repository due to dataset size considerations.
